# CLAUDE.md

**`AGENTS.md` is canonical.** Read it first. This file only records what is
specific to Claude Code, so the two can never contradict each other.

## Claude Code specifics

- Agent lanes live in `.claude/agents/`. The lane roster and what each owns is in
  `AGENTS.md` § Project specialists.
- Workflow commands live in `.claude/commands/opsx/`, generated by the OpenSpec
  CLI: `/opsx:propose`, `/opsx:explore`, `/opsx:apply`, `/opsx:update`,
  `/opsx:archive`, `/opsx:sync`. Their backing skills are in `.claude/skills/`.
  Do not hand-edit them — `openspec update` regenerates them.
- `/verify` is Readr's own skill: the full build, test, lint, and spec-validation
  sequence.
- Nested `AGENTS.md` files apply to their subtree. Read the nearest one before
  editing inside `Readr/UI/`, `Readr/Sources/`, `Readr/Data/Source/`, or
  `Readr/Data/Local/Database/`.
- Never commit on `main`. Before any change, update `main` and branch off it
  as `feat/`, `fix/`, or `chore/` — see `AGENTS.md` § Branching.

## Reading order

1. `AGENTS.md` — rules and routing
2. `architecture.md` — layers, contracts, invariants
3. `codemap.md` — where things live
4. `openspec/specs/<capability>/spec.md` — normative behavior for the capability
   you are changing
