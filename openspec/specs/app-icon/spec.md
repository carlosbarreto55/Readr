## Requirements
### Requirement: Readr app icon
The installed Readr app SHALL display custom icon artwork that identifies it as a reading app.

#### Scenario: Home Screen icon
- **WHEN** Readr is built and installed on a supported iPhone
- **THEN** its Home Screen icon displays the Readr open-book artwork

#### Scenario: Icon asset compilation
- **WHEN** the iPhone app target is built
- **THEN** the app icon asset compiles without missing-image warnings or errors
